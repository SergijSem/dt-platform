# Відображення платформи цифрового двійника електроскутера на еталонну модель ISO 23247

## 1. Склад об’єкта за категоріями OME (Observable Manufacturing Elements)

| Категорія OME | Складник електроскутера / опис |
| :--- | :--- |
| **Обладнання (Equipment)** | Електродвигун (мотор-колесо), акумуляторна батарея (АКБ), гальмівна система, контролер живлення. |
| **Персонал (Personnel)** | Водій електроскутера, сервісний інженер, розробник/дослідник та системний адміністратор / спеціаліст із безпеки. |
| **Матеріали (Materials)** | Елементи живлення акумулятора, мастильні матеріали вузлів, компоненти корпусу. |
| **Процес (Process)** | Процес руху транспортного засобу, розряджання та заряджання АКБ, розгін і гальмування. |
| **Приміщення (Facility)** | *Порожня категорія:* електроскутер є мобільним міським транспортним засобом і не прив'язаний до стаціонарного виробничого приміщення. |
| **Довкілля (Environment)** | Зовнішнє середовище експлуатації (температура довкілля, дорожнє покриття, вологість). |
| **Продукт (Product)** | Послуга перевезення пасажира та міської мобільності, телеметричні дані поїздки. |
| **Документація (Documentation)** | Технічний паспорт електроскутера, інструкція з експлуатації, журнали логів і подій. |

## 3. Пояснення статусів та розрахунок покриття

### Пояснення статусів неочевидних сутностей:
* **Наскрізна: Якість даних (Не закрито):** Це забута функція на поточному етапі проєктування (модуль автоматичної валідації викидів та фільтрації аномальних значень у телеметрії ще не реалізований на рівні серверної частини). Планується додати в наступних лабораторних роботах.
* **Категорія OME «Приміщення» (Порожня):** Свідоме обмеження, оскільки об'єкт є мобільним транспортним засобом поза виробничим цехом.

### Розрахунок покриття еталонної моделі ($C$):
Загальна кількість базових сутностей за еталонною моделлю дорівнює **9**. Оскільки всі 9 сутностей є застосовними до нашого класу об'єкта ($n_{\text{етал}} = 9$), а відповідники наявні для **8** із них ($n_{\text{відп}} = 8$), покриття обчислюється за формулою:

$$C = \frac{n_{\text{відп}}}{n_{\text{етал}}} \cdot 100\% = \frac{8}{9} \cdot 100\% \approx 88.9\%$$
