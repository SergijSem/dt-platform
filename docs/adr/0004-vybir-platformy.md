# ADR-0004: Вибір платформи цифрового двійника

## Статус

Прийнято

## Контекст

Для реалізації цифрового двійника електроскутера необхідно обрати платформу, яка забезпечуватиме зберігання моделі об'єкта, оновлення його стану та інтеграцію з іншими компонентами системи.

Для порівняння розглянуто Eclipse Ditto, Azure Digital Twins та AWS IoT TwinMaker. Оцінювання виконано за критеріями відкритості, масштабованості, вартості володіння, можливості локального розгортання, підтримки протоколів та зрілості спільноти.

Результати порівняння наведено в `docs/platform.md`.

## Розглянуті альтернативи

1. **Eclipse Ditto** — відкрита платформа для створення та керування цифровими двійниками.
2. **Azure Digital Twins** — керована хмарна платформа Microsoft для моделювання цифрових двійників.
3. **AWS IoT TwinMaker** — хмарний сервіс AWS для створення цифрових двійників та інтеграції даних із різних джерел.

## Рішення

Обрано Eclipse Ditto як платформу для реалізації цифрового двійника електроскутера.

## Обґрунтування

Eclipse Ditto отримала найвищу зважену оцінку за результатами порівняння платформ. Основними перевагами є відкритий вихідний код, підтримка різних протоколів обміну даними та можливість локального розгортання.

Крім того, платформа вже розгорнута в середовищі проєкту за допомогою Docker Compose, що дає змогу використовувати її без залежності від зовнішньої хмарної інфраструктури.

## Наслідки

- Модель цифрового двійника електроскутера реалізується на базі Eclipse Ditto.
- Для опису об'єкта використовуватимуться Thing, attributes та features.
- Обмін даними здійснюватиметься через механізми інтеграції Eclipse Ditto.
- Платформа розгортатиметься локально за допомогою Docker Compose.
