# Платформа цифрового двійника електроскутера

Платформа призначена для оперативного моніторингу в реальному часі, збирання телеметричних даних (8 сигналів), збереження історії, аналізу стану, предиктивної аналітики та двостороннього керування режимами роботи електроскутера.

## Загальна інформація про модель
* **Мова моделі:** SysML 1.6
* **Середовище моделювання:** Eclipse Papyrus
* **Опис архітектури:** Відповідно до ISO 23247 та ISO/IEC/IEEE 42010

---

## Структура репозиторію

* **`README.md`** — загальний опис об'єкта, мови моделі та інструкція з перегляду.
* **`docs/`** — архітектурна документація проєкту:
  * `requirements.md` — опис об’єкта, реєстр сигналів, функціональні (FR) та нефункціональні (NFR) вимоги.
  * `sources.md` — аналіз 5–6 наукових джерел із порівняльною таблицею.
  * `iso23247-mapping.md` — категорізація OME, таблиця відповідності еталонній моделі ISO 23247 та розрахунок покриття $C$.
  * `latency.md` / `latency.py` — розрахунок наскрізної затримки, Python-модель процесів та оцінка гіпотези Г-01.
  * `traceability.md` — матриця трасовності вимог із розрахунком покриття ($C_т = C_в = 100\%$).
  * `adr/` — записи архітектурних рішень (ADR-0001, ADR-0002, ADR-0003).
  * `diagrams/` — Mermaid-діаграми (контекстне, компонентне, розгортання, потік даних) у форматах `.mmd` та `.svg`.
* **`model/`** — модель системи в середовищі Eclipse Papyrus (`.uml`, `.notation`, `.di`).
  * **`model/export/`** — експортовані графічні діаграми системи у форматі SVG.

## Як переглянути модель та діаграми

1. **Готові графічні діаграми (без додаткового ПЗ):**
   Усі експортовані діаграми SysML (модель вимог, структура BDD, діяльність) доступні для перегляду у папці [`model/export/`](./model/export/). 
   Архітектурні подання (C4/Mermaid) розташовані у папці [`docs/diagrams/`](./docs/diagrams/).

2. **Відкриття проєкту в Eclipse Papyrus:**
   * Встановіть **Eclipse Papyrus** із розширенням **SysML 1.6**.
   * У меню натисніть `File -> Import -> General -> Existing Projects into Workspace`.
   * Вкажіть шлях до папки `model/` цього репозиторію та відкрийте проєкт.
